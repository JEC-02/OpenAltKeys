OpenAltKeys Settings

Free & open-source Office Alt key-tips for Google Workspace

How to use

Open Google Sheets, Docs or Slides and press Alt (Option on Mac). Excel / Word / PowerPoint style key-tips appear — type the letters you know, e.g. Alt H V V pastes values in Sheets. Esc closes, F10 cycles tip modes (shown → ghost → hidden), F4 repeats the last command, and Ctrl + + / − insert or delete rows and columns.

Where it works

Extras

Disabled sequences

Comma-separated sequence prefixes for OpenAltKeys to ignore — e.g. HV switches off the whole Home ▸ Clipboard branch, HVV only Paste Values. Ignored sequences are skipped entirely on every path — typed on the page, typed while the tips bar has focus, even clicked in the panel: no key of the sequence is ever typed into the document. Useful when a sequence collides with your own habits.

All shortcuts

The same searchable cheat sheet as the toolbar popup. Entries marked guide show instructions for actions Google has no shortcut or automation for.

About
